# v0.1.0 release notes

**Status: pre-1.0 — not production ready.** Foundation complete; M5
qualification deferred (ADR-0001). Security/compat claims need M5 evidence.
Date: 2026-11-08 (placeholder; human sets the real tag date).

## What's in

- M1–M4 complete: schemas, auth/PKI, QUIC transport, WAL/snapshot store,
  BLAKE3 chunkstore, metadata state machine, raft driver, quorum writes,
  leases + locks + cache, FUSE strict mount (caller creds, direct-I/O,
  errno table, lifecycle), POSIX surface (Link/Readlink/FsyncDir), durable
  client journal, chunk GC, joint-consensus membership, CLI validation,
  systemd units, fault harness (8 kinds).
- Locks fix: family separation, same-owner merge, BlockingGrant wake.
- 3-node Alpine container fleet with separate per-node data volumes.
- `docs/spec/status.md` — honest per-milestone state with evidence.

## What's partial / known limitations

- `docs/known-limitations.md` — xattrs/ACLs fail closed; no offline mode;
  no coordinator persistence wiring yet; WAL/chunk/metadata caveats #7–#13.
- `docs/posix-compat.md` — matrix with per-operation status.
- Benchmarks are in-process only (`docs/benchmarks/`, `results.json`) —
  not §11 qualification. No target-app suite (M5-02 deferred).

## Upgrade / compat notes

- No wire-compat promise beyond M1–M4: `api/v1` is baseline-guarded
  (`make proto-breaking`). Re-bootstrap a fresh cluster on upgrade.
- CLI exit codes changed (2 usage, 1 missing file/dir) — scripts must check them.
