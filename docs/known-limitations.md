# Known limitations

Honest register. Nothing on this list is silently dropped. Items 7–13 come
from the adversarial audit in `research/01-critic-findings.md` +
`research/02-tester-evidence.md` (2026-11-08); audit fixes are listed where
landed, with residual caveats where they remain.

| # | Limitation | Impact | Recovery / path |
| --- | --- | --- | --- |
| 1 | xattr / ACL namespaces | PARTIAL | `user.*` with non-empty suffix live (Handler: bare `user.`/NUL -> EINVAL, `security.selinux` -> EPERM, else EOPNOTSUPP; state machine rejects non-`user.*` as `ErrCommandFailed`); ACL policy enforcement pending |
| 2 | writable shared mmap | EXCLUDED, no handler yet | none (excluded by design; add an explicit FUSE `Mmap` handler returning `EOPNOTSUPP` — today the kernel gets the default ENOSYS) |
| 3 | O_DIRECT explicitness | `EINVAL` on Linux in strict mode (`oDirectFlag` build-tagged; 0 off-Linux) | use streaming reads |
| 4 | offline writes | unavailable | designed out (strict volume) |
| 5 | target-app qualification | deferred to M5 (ADR-0001) | needs reference hardware + chosen target app |
| 6 | persisted metadata index beyond Raft | in-memory scaffold (projection durable, WAL snapshot pending) | `metadata.Encode`/`Decode`/`Persist` (checksummed JSON envelope, atomic tmp+rename+fsync) + daemon `LoadPersisted` + WAL-tail replay landed (`TestPersistRoundTrip`, `TestThreeDaemonClusterRecovery`); `daemon.Snapshot()` writes cluster/volume-bound Raft snapshot via `WriteSnapshotFileWithIDs`. Pebble remains the chunk index only. Full snapshot-transfer + compaction truncation remain pending #7. |
| 7 | WAL snapshot + compaction | FIXED for restore/gap (snapshot restored on reopen; gap validated before write; mid-log corruption fails closed). `Compact` still refuses beyond snapshot (durable compaction pending). | manual: re-bootstrap node from verified snapshot; do not rely on `Compact` until durable |
| 8 | metadata determinism + parents | FIXED (deterministic SHA256 IDs from `(OpID, parent, name)`; parent checks in Link/Rename; Rename no-overwrite in the state machine; Truncate cap 32 MiB; bare-xattr reject; LinkCount zombie-free). Note: the Handler surface allows flat-root overwrite with EISDIR/ENOTDIR/ENOTEMPTY checks and caps at 16 MiB — the two surfaces diverge, see `docs/posix-compat.md` | — |
| 9 | chunkstore corruption + dedup | FIXED for mid-pack skip + dedup verify (+ bounds + nil-pack guards). `TestTornWriteRecovered`: torn tail truncated on reopen; first committed chunk survives; amputated-sync chunk is dropped or `ErrCorrupt`, never silently wrong (quarantine is skip, not forensic copy). | manual: scrub + repair from majority |
| 10 | enrollment + role enforcement | PARTIAL (empty-proof rejected; `VerifyConnection` wired (`VerifyConnectionFunc`) + per-stream `AllowedPrincipalForClass`/`AcceptClassifiedStream` enforced. `MemoryStore.TryConsume` is atomic (single-lock check-and-burn; `TestConcurrentConsumeExactlyOneSucceeds` proves exactly one concurrent win) and `Consume` delegates to it. Generic non-atomic stores still use Get-then-Mark, which is NOT atomic — production stores must implement `AtomicEnrollmentStore`. Opener role is now enforced inside `OpenClassifiedStream(conn, self, class)` (requires the local identity); `AcceptClassifiedStream` re-checks the peer. | manual: rotate enrollment nonces; use atomic stores only |
| 11 | volume coordinator | FIXED for sentinel/ctx/batch (wraps `ErrNoQuorum`; honors `ctx`; pre-validates batch; monotonic RaftIndex) | orphan sweep via GC remains the safety net |
| 12 | transport framing | FIXED for zero-length + per-class caps + single-writer mutex | — |
| 13 | benchmark qualification gap | numbers are in-process / Docker VM only (no QUIC/FUSE/10 GbE); §11 targets UNVERIFIED | run §11 gates on reference hardware — see `docs/benchmarks/README.md` |
| 14 | driver chunk-gap gating | FIXED for campaign + deferred apply + tick gating + volume serve-gate (`TestApplyDeferredForMissingChunk`, `TestCampaignRefusedWithChunkGap`, `TestGappedTickDoesNotElect`, `TestGappedLeaderCannotServe`, `TestVolumeConsultsRealDriverChunkGap`; log-wide scan incl. uncommitted; vote-grant ungated per G-2) | fetch+verify missing chunks, call `RetryApply`; review driver tests before production use |
| 15 | FUSE inode tree + open flags + durability | PARTIAL (nil-handler fails closed (`TestNilHandlerFailsClosed`), `O_DIRECT` → `EINVAL` on Linux via `oDirectFlag` (build-tagged), strict default fail-closed (`NewStrictHandler` + `TestStrictHandlerFailsClosed`/`TestFsyncTruncateFailClosed`/`TestHandleFsyncFailClosed` — writes, `Truncate`, `Fsync`/`FsyncDir`, and handle fsync return `EIO` with no coordinator; `NewHandler` is the test-only (Noop) surface). `Root.Lookup`/`childNode.Lookup` + `Readdir` now walk arbitrary depth in-memory (`tree.go`: `MkdirPath`/`createFilePath`, `TestNestedTree` proves `a/b/c/file`); kernel `Forget`, cross-directory rename, and metadata inode-ID binding remain pending. Namespace mutations (`Create`/`Mkdir`/`Link`/`Rename`/`Unlink`) still mutate the in-memory Handler without a coordinator call (only Write/Truncate/Fsync call `Syncer`) — full T03 wiring (Handler→`volume.Coordinator` via Raft) is pending. | bind Handler to metadata inode IDs; test nested `ls` via `/dev/fuse`; route every mutation through the coordinator |
| 16 | blocking locks | FIXED (manager + state-machine: `BlockingGrantCtx` cancellable + `ErrDeadlock` (cross-inode BFS, chaos j1 PASS), family queues `(Inode,Family)`, `ApplyReleases`/`Release` wake, metadata `LOCK_GRANT`/`LOCK_RELEASE` now apply via `BindProto` (atomic clone, `Clone`); `BlockingGrant` remains as the unbounded wrapper for compat.) | callers should migrate to `BlockingGrantCtx` with a deadline |
| 17 | group commit + daemon wiring | spec §11 group commit (0–5 ms, leader-only batching) not implemented; coordinator is in-process fan-out; `daemon` is now a real composition root (`internal/daemon`: WAL/chunk/metadata recovery, Raft driver, QUIC peer mesh with persistent conns, live `/healthz` vs `/readyz`, bounded shutdown) with 3-daemon recovery/restart tests, but the QUIC 3-process leader-election proof is still pending (in-memory `testkit/cluster` remains election evidence) and `mount` still calls `KernelMount` with a strict handler (fail-closed without `/dev/fuse` or a coordinator) | M5 work; until then the fleet test (`go test`) is the verification surface |
| 18 | op retry after eviction | retained results bounded (10,000 entries; server by Raft index, client journal 10 min). A retry past the window is forgotten and may re-execute (double-apply). Clients must surface `EIO` and reconcile with a new op-ID — see `docs/failure-semantics.md` | reconcile by content (new op-ID with preconditions), never blind re-execute |

Rule: nothing here is a compatibility or performance certification.
